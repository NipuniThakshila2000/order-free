# order-free

Appointed Seasons is a free browser reading based on the supplied historical source notes. Open `index.html` directly or serve this folder with `node server.mjs`.

The reading code lives in `src/*.mjs`. After changing those modules, run `node scripts/build_browser.mjs` to refresh the browser bundle used by the standalone HTML page.

See `SOURCE_NOTES.md` for the calculation rules and limits.
